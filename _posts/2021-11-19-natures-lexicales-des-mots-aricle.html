Ce cours forme une base indispensable à un bon début de votre apprentissage de français. Il vous permet de construire une vision exhaustive sur les composants lexicaux des discours écrits ou oraux. Ce cours concerne l'étude des catégories lexicales, également appelées parties du discours. Les mots de dictionnaire sont catégorisés dans des types et sous-types. Cela facilite l'étude et l'emploi de la langue : il est important pour comprendre comment les mots peuvent se combiner pour former des expressions et des phrases. En français, les mots prennent neuf natures lexicales : l'article, le noms, le pronom, le verbe, l'adverbe, l'adjectif, la préposition, la conjonction et l'interjection. Chacune de ces catégories a ses propres propriétés linguistiques. Dans cet article, nous couvrons les natures lexicales des mots, avec des définitions et des exemples simples et clairs. 

1- L'article 

Les articles sont des mots permettant d’introduire un nom ou d'un groupe nominal.
Types
Articles définis : le, la, les.
Article indéfinis : un, une, des.
Articles partitifs : du, de la, des.
Articles contractés : au, aux, du, des.
Exemples
La balle est dans le terrain.
Un écrivain a produit des romans.
J'ai bu du thé et mangé de la confiture

2- Nom

Le nom est un mot qui désigne les êtres, les choses et les idées, qui peut s’associer à un déterminant ou à un adjectif.
Types
Nom propre : Sami, Rabat, Microsoft, 
Nom commun : fenêtre, tête, route, 
Nom simple : machine, porte, arbre, 
Nom composé : machine à laver, porte-clés
Nom abstrait : amour, intelligence, paix
Nom concret : montre, balle, téléphone, 
Nom individuel : cahier, fourchette, 
Nom collectif : gens, foule, groupe, 

3- Pronom

Le pronom est un mot qui peut prendre la place d’un nom ou d'un pronom.
Types 
Pronom personnel sujet : je, tu, il, elle, nous, vous, ils, elles, on
Pronom personnel réfléchi : me, te, se, nous, vous, se.
Pronom personnel tonique : moi, toi, soi, lui, elle, nous, vous, eux, elles.
Pronom personnel COD : me, te, le, la, nous, vous, les.
Pronom personnel COI : me,te lui, nous, vous, leur.
Pronom démonstratif : celui, celle, ceux, celles, cela, ça.
Pronom possessif : le mien, le tien, le sien, le nôtre, le vôtre, le leur, les miens, les tiens, les siens, les nôtres, les vôtres, les leurs, la mienne, la tienne, la sienne, la nôtre, la vôtre, la leurs, les miennes, les tiennes, les siennes, les nôtres, les vôtres, les leurs.
Pronom interrogatif : qui, que, quoi, lequel, laquelle, lesquels, lesquelles.
Pronom relatif simple : qui, que, dont, où.
Pronom relatif composé : lequel, laquelle, lesquels, lesquelles, duquel, de laquelle, desquels, desquelles, auquel, à laquelle, auxquels, auxquelles.
Pronom indéfini : aucun, chacun, plusieurs, certain, tout, peu, beaucoup, on

Exemples
Je travaille dans le domaine de l'enseignement.
Je me réveille tôt pour se rendre à l'école.
Je fais ma valise moi-même.
Cette personne, je la connais très bien.
Je lui donne un conseil.
Le bon élève est celui qui est sérieux dans ses études.
Sa maison est plus grande que la mienne.
Qui veut être riche ?
Voilà la maison où je suis né.
Aucun ne parle l'allemand ici.

4- Adjectif

Ce mot sert à désigner les qualités et les propriétés d'une chose. Il s'accorde avec le nom auquel il se rapporte.
Types 
Adjectif qualificatif : beau, agréable, intelligente, rapide, courtes, ...
Adjectif démonstratif : ce, cet, cette ces.
Adjectif possessif : (mon ma mes), (ton ta tes)
(son sa ses), (notre votre leur), (nos vos leurs).
Adjectif numéral cardinal : un, deux, trois, ...
Adjectif numéral ordinal : premier, deuxième, troisième, ...
Adjectif indéfini : aucun, chacun, certain, plusieurs, quelque, ...

Exemples
La ville que j'ai visitée est magnifique.
Attention ! Ce chien est dangereux.
J'aime mes amis.
J'ai deux questions à vous poser.
Les premiers élèves de classe participeront à la compétition.
Quelques pannes nous ont empêchés de continuer.

5- Adverbe

C'est un mot généralement invariable qui modifie le sens des verbes, des adjectifs et des adverbes.
Types 
Adverbe de quantité : beaucoup, peu, assez
Adverbe de lieu : là, ici, ailleurs, partout, loin, ...
Adverbe de temps : Maintenant, hier, aussitôt, autrefois, avant, bientôt, d'abord, déjà, demain, encore, enfin, ensuite, aujourd'hui, ...
Adverbe manière : simplement, facilement, bien, mal, doucement, mieux, ...
Adverbe d'affirmation : oui, sûrement, d'accord, assurément, bien, bien sûr, certainement, certes, exactement, oui, parfaitement, précisément, si, volontiers, vraiment, ...
Adverbe de négation : ne, pas, jamais, plus, guère, point, rien, ...
Adverbe de doute : peut-être, probablement, apparemment, vraisemblablement, ...
Adverbe d'interrogation : combien, comment، pourquoi, quand, où.
Exemples
Je connais peu de mots en espagnol.
Ici, je trouve du calme.
Demain, j'aurai besoin de votre aide.
Je préfère les profs qui expliquent simplement les cours.

6- Verbe

C'est un mot qui exprime une action ou un état de sujet. On reconnaît le verbe au fait qu'il se conjugue (il change sa terminaison selon le nombre, la personne, le temps, le mode).
Types 
Verbe transitif direct (s'utilise avec un COD)
Verbe transitif indirect (s'utilise avec un COI)
Verbe intransitif (s'utilise sans COD ni COI)
Verbe auxiliaire : avoir, être, aller, venir, ...
Verbe attributif : être, paraître, sembler, demeurer, rester, devenir, passer pour, s'appeler, se nommer, ...
Verbe impersonnel : pleuvoir, neiger, venter, s'agir, ...
Verbe pronominal : se balader, s'exclamer, se réjouir, se réveiller, ...

7- Préposition 

La préposition se place devant le nom. Elle assume une fonction syntaxique et sémantique dans la phrase.
Types
Préposition simple : à, de, avec, pour, sur, sous, en, 
pendant, durant, derrière, devant, contre, 
Locution prépositive : à cause de, en raison de, au-dessous de, au-dessus de, à côté de, ...
Exemples
J'étudie pour réussir ma vie.
Il s'est absenté en raison de sa maladie.
J'attendais son arrivée depuis deux mois.
Un étranger s'est installé devant moi.
Je peux écrire avec une plume.

8- Conjonction

Cette nature lexicale unit (assemble) entre les mots et les groupes des mots.
Types 
Conjonction de coordination : mais, ou, et, donc, or,ni, car
Autres mots coordonnants : aussi, en effect, c'est pourquoi, par conséquent, alors, ceci dit, puis, néanmoins, ensuite, ainsi que, bien plus, de plus, ...
Conjonction de subordination que, comme, lorsque, quand, 
Locutions conjonctives de subordination : 
Pour que, selon que, en attendant que, avant que, après que, dès que, depuis que, tandis que, aussitôt que, jusqu'à ce que, parce que, puisque, de sorte que, de façon que, de peur que, ...

9- Interjection

Dans le discours, écrit ou oral, on se sert des interjections pour exprimer les mouvements de l'âme et les sensations.
Exemples
Ah ! Oh ! Ouf ! Zut ! Hélas ! Chut !
