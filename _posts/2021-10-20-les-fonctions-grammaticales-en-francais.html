Introduction

En français, les fonctions grammaticales jouent un rôle essentiel dans la construction des phrases. Elles permettent de comprendre comment les mots s’organisent et interagissent entre eux pour donner du sens à ce que l’on dit ou écrit. Chaque mot ou groupe de mots peut avoir une fonction spécifique, comme sujet, complément ou encore attribut. Ce cours vous aidera à identifier ces fonctions et à mieux analyser les phrases afin d’améliorer votre expression écrite et orale.

Sujet

  • Le sujet fait l'action.
  • Le sujet peut être un pronom personnel (je, tu, il, elle, nous, vous, ils, elles, on).
  • Le sujet peut être un nom ou un groupe nominal.
  • Le sujet répond à la question (Qui fait l'action ?)

Exemples : 
• Les élèves étudient le français.
• Il paraît courageux.

Complément d'objet direct

  • Le COD complète le verbe.
  • Le COD répond aux questions ( ....quoi ? ....qui ?)
  • Le COD peut être un nom.
  • Le CD peut être un groupe nominal.
  • Le COD peut être un pronom personnel (me, te, le, la, nous, vous, les).

Exemples :
• Il restitue un poème.
• Il le rédige rapidement.

Complément d'objet indirect

  • Le COI complète le verbe.
  • Le COI répond aux questions (..... à qui ? / ..... de qui ? / ...... à quoi ? /........de quoi ?)
  • Le COI peut être un nom.
  • Le COI peut un groupe nominal.
  • Le COI peut être un pronom (me, te, lui, nous, vous, leur).

Exemples :
• L'enfant pense à sa mère.
• Il parle leur poliment.

Complément d'objet second

Ce complément vient après un COD ou un COI.

Exemples :
• J'ai expliqué une information à mon ami.
• Ali parle de ses projets à son épouse.

Attribut de sujet

L'attribut de sujet donne une précision sur le sujet par l'intermédiaire d'un verbe d'état (être, devenir, rester, demeurer, avoir l'air, passer, s'appeler, ...etc.)

Exemples : 
• Après la course, tout le monde est épuisé.
• Ce malade semble souffrir.

Complément d'agent

Il désigne l’être ou la chose qui est l’auteur de l’action exprimée par le verbe.

Exemples :
• Le voleur est arrêté par la police.
• Ce directeur est craint de tous.

Déterminant

  • Détermine un nom : indique son genre et son nombre.
  • Il est généralement placé avant le nom.
  • Le déterminant peut être un article, un adjectif démonstratif, un adjectif numéral, un adjectif indéfini, un adjectif possessif.

Exemples : 
• Le roman / Ce tableau / Cinq grammes / Quelques fautes / Son livre.

Épithète

L'épithète est un adjectif placé juste à côté du nom qu'il qualifie.

Exemples : 
• C'est une histoire étrange.
• Les problèmes que j'ai rencontrés sont durs.

Complément de nom

Le complément de mon complète un nom.

Exemples :
• La fin de l'épisode était longue.
• Les jeunes d'aujourd'hui sont plus ouvert sur le monde.
• J'ai une envie de voyager.

Complément d'adjectif 

Le complément d'adjectif complète un adjectif.

Exemples :
• Sami est fière de son travail.
• Elle est capable de monter l'escalier.
• Elle est sûre qu'elle va gagner.

Complément d'adverbe

Le complément d'adverbe complète un adverbe.

Exemples :
• Il n'avait pas assez de temps.
• Heureusement pour lui, la porte est ouverte.
• Il retourne là où il est né.

Complément de pronom

Le complément de pronom complète un pronom.

Exemples : 
• Lequel de ces stylos est le tien ?
• Joueur très brillant, il a marqué trois buts dans le dernier match.

Complément d'interjection

Le complément d'interjection complète une interjection.

Exemples :
• Attention à vous !

Conclusion

Comprendre les fonctions grammaticales est indispensable pour bien s’exprimer et éviter les erreurs. Grâce à ce cours, vous savez maintenant reconnaître les principales fonctions dans une phrase et leur rôle. Plus vous vous entraînerez, plus cela deviendra facile et naturel. N’oubliez pas : la grammaire est un outil qui vous permet de mieux communiquer et de vous faire comprendre clairement !
