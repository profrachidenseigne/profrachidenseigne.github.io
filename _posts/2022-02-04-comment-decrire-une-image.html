Dans la vie quotidienne et aussi dans nos rêves, les images jouent un rôle crucial dans notre conception de monde, quel qu'il soit réel ou imaginé. Par le moyen de l'image on peut communiquer un message, modifier un comportement, ou inciter à l'action.
Vous allez apprendre, dans cet article, les principaux éléments qui forment une base d'une description objective de l'image. 
Commençons !

Les types


Image fixe : peut être une photographie, une cartographie, un dessin, une vignette d'une bande dessinée, une image de synthèse, une caricature, un tableau (peinture), une affiche …etc.      
Images animées : sont des séquences d'images comme les films et les émissions.

Les formes

Voici les formes les plus communément utilisées comme des contours possibles d'images.

Le cadrage de plan  


  • Plan général : situe le personnage dans son environnement (ville, paysage, foule).
  • Plan d'ensemble : montre l'interface d'un bâtiment ou un personnage.
  • Plan moyen : cadre un ou plusieurs personnages en entier.
  • Plan américain : montre un personnage jusqu'à mi-cuisses.
  • Plan rapproché : montre la partie supérieure du corps (poitrine et tête).

Les points de vue 


Le point de vue est l'endroit où l'image est prise. Pour Prendre une photo, on peut se positionner dans plusieurs places selon nos choix, on appelle ces places, des points de vue.
  • Hauteur d'œil : le sujet est en face de photographe. 
  • Contre-plongée : le sujet est au-dessus de photographe. 
  • Plongée : le sujet est sous le photographe.

Le contenu de l'image

Description de lieu : il s'agit de présenter brièvement la portion de l'espace vue dans l'image (si elle existe).
Description des personnes/personnages : faire une présentation de ce qu'on trouve dans l'image : personne, personnage, ou autre créature, est à la base de bonne description d'image.

La Lumière 

La lumière peut être naturelle (de la nature (soleil, lune, feu, étoiles)) ou artificielle (n'est pas naturelle), intense (forte) ou douce.
La source de lumière (soleil, lampe, bougie, …etc.). 

Les types de lumière 

  • Lumière directe : éclaire directement le sujet dans l'image.
  • Lumière indirecte : éclaire indirectement le sujet dans l'image.
  • Lumière diffuse : est une lumière directe qui passe à travers une surface avant d'éclairer le sujet de l'image.
  • Lumière réfléchie : est une lumière indirecte, qui a changé sa direction (réorientée par un mur, miroir, surface).
  • Le contre-jour : la lumière se trouve derrière le sujet, et ce sujet est en face de photographe.
  • Lumière latérale : la lumière vient de la droite ou de la gauche.

Les couleurs

  • Couleurs claires / Couleurs sombres (couleurs foncées)
  • Couleurs vives (saturées) / Couleurs ternes (non saturées).
  • Couleurs primaires :( jaune, rouge et bleu) / Couleurs secondaires :( orange, vert et violet).
  • Couleurs chaudes :( sont à base de jaune) / Couleurs froides :(sont à base de bleu).

Le sujet de l'image 

Chaque image, en tant qu'un produit destiné à être vue, renferme un ensemble de significations et d'interprétations. Une image peut cibler un ou des sujets à la fois. Voici des exemples : (environnement, sport, science, cinéma, littérature, économie, ...etc.)

Le(s) message(s) de l'image 

Le producteur de l'image peut communiquer un ou des messages par le moyen de son image. Voici quelques exemples : (encourager, interdire, dénoncer, cultiver, demander, sensibiliser, ...etc.)
