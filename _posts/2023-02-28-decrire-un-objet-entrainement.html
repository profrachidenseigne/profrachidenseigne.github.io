Le pouvoir de la description réside dans le fait d'utiliser des mots pour peindre une image. La description est l'art de choisir et d'employer de bons mots pour créer une image vivante de quelque chose ou de quelqu'un dans l'esprit du lecteur ou de l'auditeur. La description peut rendre votre écriture plus engageante, informative et persuasive. Cela peut également vous aider à transmettre vos émotions, votre humeur et votre ton. Mais comment rédiger une bonne description ? Dans cet article vous allez apprendre comment décrire un objet en employant les différents outils linguistiques et stylistiques.

Qu'est ce que vous pouvez décrire en regardant un objet ?

Chaque objet concret fournit à l'oeil de l'observateur différents aspects :
La forme : (carré, rond, cylindrique, ... etc.)
La taille : (grand, petit, énorme, ... etc.)
La couleur : (rouge, vert, blanche, ... etc.)
L'emplacement : (... situé dans le coin de salon, ... est au milieu d'un beau jardin, ... se trouve à côté d'une bibliothèque, ... etc.).
Les composants : (muni d'un couvercle, à quatre pieds, il a un manche très large, ... etc.)
La fonction : (... permet de climatiser la pièce, ... conçu pour faciliter les tâches des techniciens, ... sert à nettoyer les toits, ... etc.)
La matière : (avec revêtement en cuivre, un paquet de bois foncé, c'est un sachet en plastique, ... etc.)
La qualité (... est très utile, ... est d'une qualité moyenne, ... est de très bonne qualité, ... etc.)
Vous pouvez également exprimer votre opinion sur l'objet regardé.

Quels sont les procédés linguistiques à utiliser pour faire une bonne description ?

La comparaison
Exemple : Il paraît comme une chose extraordinaire.
Énumération
Exemple : C'est un vase magnifique, nouveau et très coûteux.
Proposition subordonnée relative
Exemple : C'est un objet qui coûte cher.
Phrase exclamative
Exemple : Quelle longue robe!
Adverbe d'intensité
Exemple : Il est très utilisé. ... est bien faite. 
  En utilisant ces procédés et en choisissant les bons mots, vous pouvez très facilement composer un texte descriptif de bonne qualité.
